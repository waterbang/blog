# 前言

2025年写点什么呢? 今年AI发展太快了，让我觉得写技术文章已经过时了（一年比一年文章少的借口）。今年是Agent元年，AI已经完全的改变了我们的开发方式，所以就以agent的改变来切入今年的年终终结吧。希望我老了还能看得懂这些记录。

## 开发方式彻底改变

今年的agent的开发方式，从直接对话框复制代码 -> 到 IDE 自动写代码 -> 到[Claude code / Codex] 。

然后逐步的在探索一些自动化工作流。当前这个时间点下，模型的发展比较逐步成熟，大家开始在探索软件工程化的一些实践，并且和agent结合，来替代传统的开发流程。相信2026年会有更多令人兴奋的模型和工具出现，进一步争强或者改变软件开发的整个范式。

当前最流行的是MCP和Skills协议，它们为Agent的可组合性和标准化提供了新的可能性，让开发者能够更灵活地构建和集成各种功能模块，极大地提升了开发效率和代码复用性，让复杂的AI应用开发变得更加模块化和可维护。这种标准化的流程使得AI应用的构建和部署变得更加高效和可靠，为AI应用的快速迭代和规模化部署奠定了基础，当前随着整个AI能力的增强特别是现在 opus4.5，gemini3,gpt5.2的组合拳之下，构建一个小应用不需要一天的时间。([cyclesync项目](https://github.com/dweb-channel/cyclesync))

既然构建速度这么快了，那么我们的技术认知就变得更加重要了，我们需要了解各个技术的适用场景，以及如何在实际项目中合理选择和组合这些技术，也就是每个人都变成架构师了，但是我现在发现，我学习的速度跟不上AI的速度，因为底层模型知道一切。

最终方法只能让AI对AI在做验证。相信这也是目前很多人在探索的方向。今年一直涌现出来的各个A2A,A2UI等协议也在说明着这一点。
