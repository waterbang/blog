## 前言

人有瞬间的创造力，也有看见原本不存在的连接的能力。AI 是人的延伸，是人的力量的增强。

当一个人可以同时调动多个 Agent，这种变化在影响我们理解价值的方式，以及人与人、人与组织之间的关系。

但是当多个 Agent 同时工作时，如果每一次交接、每一个判断都必须等待人来处理，人的注意力就会成为执行瓶颈。因此，我们需要重新设计协作环境，让任务持续的推进和完成，而不是还是Chat的模式，尽管现在来说代码已经黑盒。

## 所有可以被总结成经验的工作都会被淘汰

更准确的说，**当一项工作能够被明确描述、重复执行，并且验证结果时，在Agent下不再有价值。**

如果你在做类似的工作立马改变，除了人与人交互的行业。因为当一项工作能够被明确描述、重复执行并验证结果时，单靠掌握它的执行步骤，越来越难形成个人优势。

吕芳说过了人要：思危、思退、思变。

人的主观能动性也因此变得更重要：一个人需要主动发现值得做的事，而不只是等待下一项已经拆好的任务。因为人类具有瞬间的创造力，也就是灵光一闪，在Agent里面叫做涌现。

所以以后产品经理的岗位会越来越多。总的来说 无中生有的能力会更重要，可结构化的工作都会消失。并且学校中的知识灌输已经不是第一位。人的价值会更多地体现在定义问题、判断取舍或者是承担结果上。

## 超级个体

超级个体，简单来说是 “一个人加上很多个 Agent”。 

但是现在人类已经是Ai发展新的阻碍，当十几个Agent 同时工作的时候，人类就是瓶颈，所以真正的超级个体应该是需要能搭建 Agent 环境，并且这个环境里面，人的因素只取决于人的创造力。

这才是人机协同的最佳方式，也就是说 人 上班只需要发挥其创造力，洞察力这些Ai所不具备（当前？） 进行互补。 这样的超级个体上限就是这个人的创造力和洞察力。

核心来说就是：是把必须经过自己的判断沉淀成协作规则，让不必经过自己的事情能够持续推进。

## 群体智能

简单来说这是 超级个体再进一层，也就是一群的超级个体组成群体智能，并且随着组织形式的改变，公司的环境也会发生变化，上面所说，一些好的东西就会自然的涌现出来。

把公司看作是大模型，同事（agent）之间的交互看作是训练，自然而然的就根据环境出现智能。

这也就是Anthropic 一直在做的，智能复利，在使用大模型训练大模型。

Anthropic 的实践提供了一个例子：随着每天合并的代码变更从约 2500 次增长到超过 3 万次，原有源码管理体系成了新的瓶颈。他们借助 Claude 构建了内部版本控制系统 Scion。也就是说他们产品能力大概领先外界半年，并且还会不断变长。

因此构建的智能飞轮会更为重要，也就是Agent 得去独立去干活，并且基于真实世界的反馈，去不断的泛化发散，去渗透更复杂的任务和场景。

举个例子比如说：抖音之所以成为国民级的应用，是因为做了今日头条沉淀出了推荐算法。所以当智能飞轮转起来的时候，运气好的话就能遇到泛化能力特别强的场景。

后面的工作就是会变成：执行能力越充足，越需要有人决定做什么，并建立能让执行持续产生价值的环境。

## 碳基和硅基同事，如何一起工作

在 Agent 快速发展的阶段，值得观察的，是那些已经开始改变自己工作方法的人。

他们不只是把原来的每个步骤交给 AI 加速，而是在调整整个工作的组织方式：哪些事情可以并行，哪些事情必须等前一步完成；什么时候需要人参与，什么时候应该让 Agent 自己继续。

人与 Agent 的关系，也会从一次性的问答，变成围绕目标的持续协作。 也就是说 人和Agent共享一份上下文。

但把 Agent 叫作“同事”，不意味着它拥有和员工相同的责任能力。它可以负责执行某个环节，现实中的授权和责任仍然需要有人承接。（比如上线

## 更加激进的判断

在当下这个时间节点应该很明朗了，代码的价值已经有限，以后许愿编程会实现，也就是说程序员可能会消失，软件能否跑出来商业化能力重要程度会占到80%。特别是出了逆向能力的Rea，前端所以的混淆失效，所以接口裸奔，基本上没有后端的软件护城河已经无了。再过半年人家一句话一个星期，做得比大型企业的做得都好，并且内存占用还低。

因此提前学习商业化以及跨学科跨领域的知识是现在所必须要做的。以后的全栈指的会是跨学科跨领域的人。
